GRAPHIC DESIGN PORTFOLIO

Files:
- index.html = website
- style.css = design/style

The site uses the same cream + turquoise family as the previous portfolio, with a more editorial graphic-design layout.

TO ADD IMAGES:
1. Create an "images" folder in your GitHub repository.
2. Upload your image there.
3. In index.html, replace a placeholder with:
   <img class="logo-card" src="images/YOUR-FILE.jpg" alt="Logo">

TO ADD VIDEOS:
Use a video host for large files. Paste the hosted URL into the empty <source src=""> in the Motion Graphic section.

CV:
Upload cv-english.pdf and cv-persian.pdf to the repository. The links are already included.

CONTACT:
Replace YOUR-EMAIL@example.com and the Instagram/LinkedIn usernames at the bottom of index.html.
